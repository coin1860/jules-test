# 外汇量化交易 POC (USD/CNY)

这是一个基于 Python 和 Next.js 的外汇量化交易概念验证（POC）项目。它模拟了针对 USD/CNY（美元/人民币）货币对的自动交易系统。

## 项目架构

本项目采用前后端分离的架构：

*   **后端 (Python/FastAPI)**:
    *   负责核心交易逻辑、策略计算、市场数据获取和账户管理。
    *   使用 `yfinance` 获取实时（或延迟）市场数据。
    *   提供 RESTful API 供前端调用。
*   **前端 (Next.js/React)**:
    *   提供可视化仪表盘。
    *   实时显示价格、账户权益、交易信号和持仓情况。
    *   允许用户启动/停止交易引擎，并动态调整策略参数。
    *   展示价格走势图和历史交易记录。

## 获利原理与交易策略

### 获利原理
外汇量化交易的核心是通过程序自动捕捉市场价格的波动来获取差价利润。本项目模拟的是**趋势跟踪**策略。当识别到上涨趋势时买入（持有美元），当识别到下跌趋势时卖出（持有人民币），从而通过汇率差价实现资产增值。

### 交易策略：双均线交叉 (SMA Crossover)
本项目使用经典的**简单移动平均线 (SMA)** 交叉策略：

1.  **短期均线 (Short Window)**: 对近期价格变化敏感，反应快。
2.  **长期均线 (Long Window)**: 反映长期趋势，较为平滑。

**交易信号：**
*   **金叉 (Golden Cross) -> 买入 (BUY)**: 当短期均线由下向上穿越长期均线时，视为上涨趋势确立，执行买入美元操作。
*   **死叉 (Death Cross) -> 卖出 (SELL)**: 当短期均线由上向下穿越长期均线时，视为下跌趋势开始，执行卖出美元操作。
*   **持有 (HOLD)**: 当没有发生交叉时，保持当前仓位。

## 运行指南

### 前提条件
*   **Python 3.10+**
*   **Node.js 18+**
*   无需真实的交易账户（本项目为纯模拟环境）。

### 1. 启动后端 (Backend)

在项目根目录下：

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动 API 服务
# 注意：确保在项目根目录运行，以便 python 能够正确解析包路径
python -m uvicorn backend.app.main:app --reload --port 8000
```

后端启动后，API 文档可在 `http://localhost:8000/docs` 查看。

### 2. 启动前端 (Frontend)

新开一个终端窗口，进入 `frontend` 目录：

```bash
cd frontend

# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```

前端启动后，打开浏览器访问 `http://localhost:3000` 即可看到交易仪表盘。

## 工作原理与流程

1.  **初始化**: 启动后，系统初始化 `TradingEngine`，加载 `StrategyModule` (默认参数 Short=5, Long=20) 和 `AccountManager` (初始资金 100,000 CNY)。
2.  **运行循环**: 用户点击 "Start" 后，后台线程开始运行：
    *   每隔几秒（默认 5s）从 `yfinance` 获取 `CNY=X` 的最新价格。
    *   将价格推入策略模块，计算短期和长期 SMA。
    *   判断是否发生金叉或死叉。
3.  **交易执行**:
    *   若产生 **BUY** 信号且持有 CNY，则按当前汇率买入 USD。
    *   若产生 **SELL** 信号且持有 USD，则按当前汇率卖出 USD 换回 CNY。
    *   交易记录被保存到内存中。
4.  **实时监控**: 前端通过轮询 API (`/status`) 获取最新状态，并更新图表和数据展示。用户可以随时修改策略参数（如将短期窗口改为 10），后端会立即应用新参数进行计算。
